NASA cFS running in the browser

Each flight computer is a v86 PC running 32-bit Linux and NASA cFS, with its own boot storage and hardware watchdog. In TMR mode three computers run side by side and a voter outside them masks a computer that disagrees, then resyncs it from a healthy one.

Software TMR calculator on A

TMR_CALC adds 1, 2, 3, … once a second, so the sum must be step × (step + 1) / 2. Its state is kept and computed in three memory partitions and voted every second. Keep ECC off to see TMR do the work.
