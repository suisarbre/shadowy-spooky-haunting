Ground station
Uplink · software to the satellite

Files go up gzip-compressed in 2 KB chunks with a CRC-32 each; the satellite acknowledges every chunk and a bad one is sent again. A verified file is stored on the SD card, so it survives a reboot. The golden image is the launch image: falling back to it removes what was uplinked since.

Use the shareware doom1.wad or your own copy; it never leaves your browser except to go up to the emulated satellite.

Same game data, same keys on the same tic: Doom computes the same frames, so the satellite downlinks a hash of each frame and the ground checks it against its own. A particle that changes the satellite's copy of Doom shows up as the first frame that differs. Click the ground screen, then: arrows move, Ctrl fires, Space opens doors, Shift runs, Enter and Esc for the menu.
